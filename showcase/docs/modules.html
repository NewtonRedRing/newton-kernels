Ownership and lifetime

  • Mapped files: mapped views cannot outlive the owner object.
  • Borrowed columnar views: input storage and validity bitmaps must outlive the view.
  • CSV: owned decoding and borrowed record APIs have different lifetime contracts.
  • Caller scratch: opt-in kernels often require correctly sized, non-overlapping buffers.

Experimental extensions

The native acceleration guide documents SIMD delimiter scans, structural masks, packed integers, hash aggregation and bidirectional search. Columnar and fused processing are separately documented.

No implied ABI promise. This is a v0.1 development preview. Check the exact header and release version before depending on experimental APIs.
