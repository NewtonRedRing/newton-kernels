Design principles

NewtonKernels favors independent modules, synchronous native APIs, no mandatory third-party runtime and explicit ownership. Hardware-specific code has portable fallback paths where supported. API promises are narrower than a full analytics framework.

Source headers under include/newton remain the authoritative declarations. Detailed research reports and historical benchmark snapshots remain available in the technical documentation archive.
