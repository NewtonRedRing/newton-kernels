Start here / NewtonKernels 0.1

Build your first kernel

A reproducible path from checkout to an installed CMake consumer. No mandatory dependency downloads or service setup.

Requirements

  • CMake 3.21 or newer
  • A C++20 toolchain: GCC, Clang or MSVC
  • Supported host: Linux, macOS or Windows

1. Configure, build and test

git clone https://github.com/NewtonRedRing/newton-kernels.git
cd newton-kernels
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DNEWTON_BUILD_TESTS=ON -DNEWTON_BUILD_EXAMPLES=ON
cmake --build build --parallel
ctest --test-dir build --output-on-failure

On multi-configuration generators, pass --config Release to build and -C Release to CTest. The examples directory contains complete programs.

2. Install and consume

cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release -DNEWTON_BUILD_TESTS=OFF
cmake --build build-release --parallel
cmake --install build-release --prefix "$HOME/.local"

In your consuming CMakeLists.txt:

find_package(NewtonKernels 0.1 CONFIG REQUIRED)
target_link_libraries(your_app PRIVATE
    NewtonKernels::parsing
    NewtonKernels::memory)

Set CMAKE_PREFIX_PATH to the chosen install prefix as necessary. Windows users can choose a writable prefix rather than the POSIX home path.

3. Parse CSV rows

#include <newton/parsing/csv_parser.hpp>
#include <string_view>

int main() {
    newton::parsing::CsvParser parser;
    parser.parse("name,value\nalpha,12\n",
        [](const auto& fields) {
            // Process or copy fields within this callback.
            (void)fields;
        });
}

Owned decoded fields from the callback must not be assumed to outlive their documented scope. Borrowed record functions require the backing input to stay alive.
