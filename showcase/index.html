03 / COMPETITORS' STRENGTHS

Feature coverage matters as much as speed.

The external tools are not merely baselines. Their stronger capabilities deserve visibility even when their measured kernel latency is higher.

STL / PORTABILITY

Standard-library algorithms

Standard C++ facilities are broadly supported, familiar, and require no extra specialized library. The scan comparison tests std::count, not every highly tuned third-party SIMD implementation.

Algorithm reference ↗
CSV / FEATURE BREADTH

Vince's CSV Parser

Offers file-backed memory mapping, speculative parallel parsing, delimiter inference and DataFrame-oriented functionality beyond NewtonKernels' current simple CSV API. Our benchmark does not evaluate those features.

Feature documentation ↗
GRAPHS / ECOSYSTEM

Boost.Graph

Provides a broad ecosystem of graph algorithms and abstractions. The present comparison tests destination-target Dijkstra queries only, not Boost's full algorithm catalog or generic capabilities.

05 / RESEARCH-GRADE DISCLOSURE

Show the methodology, not just the podium.

Reproducibility is a feature. Benchmark sources, competing implementation versions, machine metadata, fixtures, raw samples, limitations, and CI provenance are all linked.

01

Identical data

Fixed deterministic seeds, matched workload counts and decoded-output digests before calculating performance differences.

02

Same environment

Each pair runs on one VM, compiler and build mode. The primary CI campaign includes all eight modules on one runner; the separate local VM campaign must not be ranked against CI. This is a shared CI runner, not pinned-frequency bare metal.

03

Transparent tradeoffs

Both times are shown; no winning case is silently dropped. Memory values are reported with attribution limitations.

04

Reproducible source

Original NewtonKernels adapters are maintained here; competitor libraries are fetched separately at documented revisions, not copied into this repository.
